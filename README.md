# Portfólio Pessoal | Lucas Melo

Portfólio pessoal e profissional desenvolvido para apresentar meu perfil, formação acadêmica, conhecimentos técnicos e projetos de desenvolvimento de software.

O projeto foi desenvolvido com HTML5 e CSS3, versionado com Git e publicado no GitHub Pages.

🔗 **Acesse o projeto:** [Meu Portfólio](https://lucasmelo01.github.io/portifolio/)

---

## Sobre o projeto

O portfólio foi inicialmente desenvolvido para fins acadêmicos e vem sendo aprimorado para apresentar uma identidade visual mais moderna, profissional e responsiva.

### Unidade 1
- Estruturação do conteúdo em HTML.
- Organização semântica.
- Versionamento com Git e GitHub.
- Publicação no GitHub Pages.

### Unidade 2
- Modernização da identidade visual.
- Aplicação de CSS, Flexbox e Box Model.
- Aprimoramento da responsividade.
- Implementação das melhorias sugeridas pelo professor.
- Inclusão da formação acadêmica e dos conhecimentos técnicos.
- Inclusão de novos projetos.
- Integração com o LinkedIn.

## Seções da página

- **Cabeçalho:** menu de navegação entre as seções.
- **Apresentação:** nome, foto de perfil e links profissionais.
- **Sobre mim:** apresentação pessoal e interesses profissionais.
- **Formação acadêmica:** graduação em Análise e Desenvolvimento de Sistemas na FAESA.
- **Conhecimentos:** lista de conhecimentos técnicos.
- **Projetos:** apresentação dos projetos desenvolvidos.
- **Contato:** canais de comunicação profissional.

## Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Media Queries
- Git
- GitHub
- GitHub Pages

## Características do projeto

- Design minimalista e profissional.
- Layout responsivo.
- HTML semântico.
- Navegação com rolagem suave.
- Identidade visual em azul e branco-gelo.
- Organização do conteúdo em cards.
- Imagem com texto alternativo para acessibilidade.
