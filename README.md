# Portfólio Pessoal

Portfólio pessoal desenvolvido para fins acadêmicos, no formato de uma landing page. O projeto é feito com **HTML** e **CSS**, está versionado no GitHub e publicado pelo **GitHub Pages**.

🔗 **Acesse o projeto:** [lucasmelo01.github.io/portifolio](https://lucasmelo01.github.io/portifolio/)

---

## Sobre o projeto

O site apresenta quem eu sou, os projetos que desenvolvi e as formas de entrar em contato comigo. O trabalho foi dividido em unidades:

Unidade 1 - Estruturação do conteúdo em HTML (seções Sobre Mim, Projetos e Contato)

Unidade 2 - HTML semântico, CSS, box model, flexbox e responsividade 

## Seções da página

- **Cabeçalho:** menu de navegação centralizado com links para as seções.
- **Sobre Mim:** foto, nome, curso e uma breve apresentação.
- **Projetos:** cards com a descrição de cada projeto e botões para o site publicado e para o código no GitHub.
- **Contato:** e-mail e perfil do GitHub.

## Tecnologias utilizadas

- **HTML5:** estrutura semântica com `header`, `nav`, `main`, `section`, `article` e `footer`.
- **CSS3:** estilização, box model, flexbox e media query para telas menores.
- **Git e GitHub:** versionamento do código.
- **GitHub Pages:** hospedagem do site.

## Estrutura de arquivos

```
portifolio/
├── index.html       # estrutura da página
├── style.css        # estilos e responsividade
├── foto-lucas.jpg   # foto usada na seção Sobre Mim
└── README.md        # documentação do projeto
```

## Como visualizar

**Online:** acesse o link do GitHub Pages no topo deste arquivo.

**No computador:**

1. Clone o repositório:
   ```
   git clone https://github.com/LucasMelo01/portifolio.git
   ```
2. Abra o arquivo `index.html` no navegador.
